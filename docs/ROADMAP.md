# Roadmap

This document tracks planned improvements and ongoing work for OpenShelf.

The project is currently functional, but still in early pilot development.

---

## Near Term

### Improve Android onboarding

Some Android devices may not consistently resolve the local node address through QR links or browser redirects.

This needs more testing and refinement.

---

### Refine enclosure builds

Current prototype enclosures are functional, but there is still room to improve:

- cable fitment
- internal mounting
- durability
- wall-mount options
- heat management

---

### Simplify content updates

Current file updates require direct microSD access.

Future revisions may make content changes easier for hosts without removing storage.

---

## Mid Term

### Long-term uptime testing

Track real-world stability over extended continuous runtime.

This includes:

- power reliability
- heat behavior
- SD card reliability
- general uptime

---

### Expand pilot placements

Continue testing nodes in different physical environments to better understand:

- user behavior
- content usefulness
- discoverability
- maintenance needs

---

## Long Term

### Broader deployment model

Refine the system into a repeatable format that can be deployed across multiple independent spaces while staying lightweight, free, and easy to maintain.
