# Deployment

This document covers the intended real-world deployment model for OpenShelf nodes.

The goal is simple: place useful local information directly into physical spaces where people can access it without needing internet, apps, or accounts.

---

## Placement

OpenShelf nodes are designed for indoor placement in spaces where people already gather.

Examples:

- cafés
- community gardens
- pop-ups
- workshops
- mutual aid spaces
- small businesses
- events

Good placement means:

- easy to notice
- easy to physically reach if needed
- near seating, counters, entrances, or waiting areas
- close to visible signage

The node itself does not need to be handled by visitors.

Only the Wi-Fi connection and QR code matter.

---

## Signage

Each deployment should include a visible sign showing:

- the OpenShelf Wi-Fi network name
- a QR code linking to the node’s local address
- simple connection instructions

Typical user flow:

1. Connect to OpenShelf Wi-Fi
2. Scan QR code
3. Browse local files
4. Download what is useful

The sign is part of the system.

Without it, most people will never know the node exists.

---

## Power

Nodes are designed for continuous low-power operation.

They can be powered by:

- wall adapters
- USB battery packs
- permanent USB power installations

Power quality matters.

Cheap adapters or unstable power sources may cause resets or uptime issues.

---

## Content Maintenance

Hosts are responsible for choosing what lives on their node.

Content can be changed by removing the microSD card and updating the files directly.

Recommended content:

- lightweight PDFs
- flyers
- schedules
- guides
- local resources
- zines

Files under 1MB generally perform best.

---

## Host Responsibilities

Running an OpenShelf node is intentionally low-maintenance.

In practice this mostly means:

- keeping the node powered
- keeping the sign visible
- updating files when needed
- checking basic operation occasionally
- OpenShelf is intended to remain free for both hosts and visitors

The system is designed to stay simple.
